# Крестики-нолики на C++

Консольная игра «Крестики-нолики», написанная на языке C++.

Учебный проект. Основная игровая логика реализована с использованием классов, функций и массивов.

## Что уже работает

- вывод игрового поля 3×3;
- выбор команды, которая ходит первой;
- автоматическое распределение крестиков и ноликов между игроками;
- ввод координат X и Y;
- проверка корректности координат;
- проверка занятости игровой клетки;
- чередование ходов игроков;
- проверка победы по горизонтали, вертикали и диагонали;
- определение ничьей.

## Как устроена программа

- `Player` — класс игрока, хранит его символ и выполняет ход;
- `printBoard()` — отображает игровое поле;
- `MakeMove()` — проверяет и выполняет ход игрока;
- `CheckWin()` — проверяет наличие выигрышной комбинации;
- `main()` — управляет игровым процессом.

## Управление

1. Выберите, кто будет ходить первым:
   - `1` — крестики (X);
   - `2` — нолики (O).
2. Введите координаты клетки в формате `X Y`.
3. Игроки ходят по очереди.
4. Игра заканчивается при победе одного из игроков или ничьей.

## Технологии

- C++
- Windows API (`windows.h`)
- Стандартная библиотека C++

## Планы по развитию

- обработка некорректного ввода (буквы вместо чисел);
- возможность начать новую партию без перезапуска программы;
- подсчёт побед каждого игрока;
- улучшение интерфейса игрового поля.
